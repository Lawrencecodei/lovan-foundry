# [Client Name] — Design Brief

Fill this in from the discovery call, before opening Claude Code to build anything.
This is the single source of truth the frontend-design skill gets steered by — treat
it as a creative brief, not a checklist.

## Business context

- **What the client does**:
- **Who the site needs to convince**: (the actual buyer/visitor, not "everyone")
- **The one action the site needs to drive**: (book a call, sign up, buy, apply...)
- **What's already been tried / rejected**: (templates, past sites, competitor sites
  the client dislikes — this is often more useful than what they say they want)

## Aesthetic direction — pick ONE and commit

Brutally minimal / Maximalist / Retro-futuristic / Organic-natural / Luxury-refined /
Playful-toy-like / Editorial-magazine / Brutalist-raw / Art deco-geometric /
Soft-pastel / Industrial-utilitarian / (invent one if none fit)

**Chosen direction**:

**Why this direction fits this client** (one or two sentences — this is what stops
the AI from hedging back toward generic):

## Concrete constraints

- **Font category** (not a specific font — a category: geometric sans, humanist
  serif, monospace-accented, etc.):
- **Color family** (not hex codes yet — a family: desaturated earth tones,
  high-contrast primary, monochrome-plus-one-accent, etc.):
- **Motion philosophy**: (one orchestrated load sequence vs. scattered
  micro-interactions vs. near-static/restrained):
- **Technical must-haves**: (CMS needs, forms, payment, multi-language, etc.)

## Differentiation

What's the one thing a visitor should remember about this site specifically —
the thing that would make them describe it to someone else?

## Reference points (optional)

Sites, brands, or physical spaces that capture the *feeling* you're going for — not
to copy, but to calibrate. Note what specifically about each one is relevant.
